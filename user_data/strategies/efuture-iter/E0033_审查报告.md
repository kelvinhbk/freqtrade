## 严重问题

### 1. custom_stoploss 公式错误（强烈推荐修复）

**位置**: `AutoResearch_iter0002_E0010_E0014_E0033.py:321-326`

```python
if trade.is_short:
    desired_stop_price = trade.open_rate * (1 - desired_pct)
    return leverage_val * (1 - desired_stop_price / current_rate)   # ← 错误
else:
    desired_stop_price = trade.open_rate * (1 + desired_pct)
    return leverage_val * (desired_stop_price / current_rate - 1)   # ← 错误
```

**问题描述**: 公式中使用了 `current_rate`（当前价格），但固定止损的返回值应当基于开仓价。数学上，这导致实际触发价格变为 `sqrt(stop_price * open_rate)`，而非策略设定的 `stop_price`。

**量化影响**:

| 阶段 | desired_pct | 预期价格移动 | 实际触发价格移动 | 杠杆后亏损 |
|------|-------------|--------------|------------------|------------|
| 0-30 min | -10.0% | -10.0% | -5.13% | -15.4% |
| 30-240 min | ~-1.65% | -1.65% | **-0.83%** | **-2.5%** |
| 240 min+ | -4.4% | -4.4% | **-2.22%** | **-6.7%** |

30-240 分钟阶段的止损极度敏感，价格仅需反向移动约 0.83% 就触发。

**修复方案**:

```python
# 简化后的正确公式（desired_pct 本身即为负值）
return leverage_val * desired_pct
```

**重要提示**: 修复后必须重新回测，因为当前所有回测结果均基于错误的止损逻辑。

### 2. bearish 变量命名与语义相反

**位置**: `AutoResearch_iter0002_E0010_E0014_E0033.py:343-346`

```python
if trade.is_short:
    bearish = current_candle["ema_50_uptrend"] and current_candle["ema_200_uptrend"]
    # ↑ 实际含义: 趋势上涨 (bullish)，但变量命名为 bearish
else:
    bearish = not current_candle["ema_50_uptrend"] and not current_candle["ema_200_uptrend"]
    # ↑ 实际含义: 趋势下跌 (bearish)，命名正确
```

**问题描述**: 做空时，`ema_50_uptrend and ema_200_uptrend` 表示双均线上涨，这是 **bullish** 信号，但变量被命名为 `bearish`。虽然当前 exit 逻辑碰巧正确（short + bullish trend = 平空），但这种命名极易在后续维护或修改时引入 bug。

**建议**: 将变量重命名为 `trend_reversal` 或 `should_exit`，并统一语义。

### 4. enter_tag 字符串拼接方式不够安全

**位置**: `AutoResearch_iter0002_E0010_E0014_E0033.py:234`

```python
dataframe.loc[long_mr_conditions, "enter_tag"] += "long_mr"
```

**问题描述**: `+=` 在 pandas 中属于 read-modify-write 操作。虽然当前各 entry 条件通过 `enter_tag == ""` 互斥，但如果未来修改条件导致重叠，tag 可能变成 `"long_mrshort_mr"` 这类混乱标签。

**建议**: 改为直接赋值以提高健壮性:

```python
dataframe.loc[long_mr_conditions, "enter_tag"] = "long_mr"
```

## 回测表现差异分析

训练集 **+429.5%** 与测试集 **+42.63%** 之间存在近 10 倍差距，可能原因包括:

1. **custom_stoploss 公式错误**: 更紧的止损导致单笔亏损更小，训练集高交易次数（1614笔）下可能累积了正期望。修复公式后回测结果可能显著变化。
2. **数据漂移**: 测试集时间段（2026-02 后）的市场波动率、趋势结构可能与训练期不同。
3. **过拟合风险**: 4 种 entry type + 4 层 exit + 38 个可优化参数，模型复杂度较高，在 5m 时间框架上容易过拟合训练期数据。
